#Hospital Management System

A console-based Hospital Management System built in Python using Object-Oriented Programming (OOP) concepts. This project simulates basic hospital operations such as patient registration, doctor management, doctor assignment, patient discharge, and generating doctor-wise reports.

## Features

 Doctor Management: Add and view doctors with their specialization.

 Patient Management: Register patients, view details, admit/discharge patients.

 Doctor Assignment: Assign doctors to patients based on specialization.

 Reports: Generate patient reports filtered by assigned doctor.

 Interactive Menu: Menu-driven console interface for easy navigation.

## Tech Stack

Language: Python 3

Paradigm: Object-Oriented Programming (OOP)

## Classes Overview
1. Patient

Stores patient details (ID, name, age, gender, disease).

Handles admission/discharge and doctor assignment.

2. Doctor

Stores doctor details (ID, name, specialization).

Displays doctor information.

3. Hospital

Maintains collections of patients and doctors.

Supports patient registration, discharge, searching, and doctor-patient mapping.
